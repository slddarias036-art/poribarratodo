    Nota metodológica

    Este sistema analiza conversación digital pública y cobertura mediática ya publicada, a partir de registros verificables con fuente y enlace de origen. No mide ni representa la intención de voto.

    Reglas de integridad aplicadas

    • No se inventan publicaciones, interacciones, comentarios, visualizaciones, tendencias, fuentes ni sentimiento.
    • Cuando una columna del CSV no existe o una celda está vacía, se muestra "Dato no disponible" — nunca se estima un valor.
    • Una tendencia no se clasifica a partir de una sola publicación; se etiqueta como "evento aislado".
    • El tono sugerido para comunicación pública es una recomendación general basada en volumen y variación observados.
    • Cobertura mediática y conversación en redes no se equiparan a opinión ciudadana representativa.
    • Cada afirmación conserva fuente, URL y fecha cuando están disponibles.

    Limitaciones actuales

    IBARRA CIVIC RADAR — herramienta de monitoreo de cobertura mediática y conversación pública con fines analíticos y académicos. No constituye asesoría de campaña ni recomendación de voto.
