Metodología y limitaciones

Nota metodológica

Este sistema analiza conversación digital pública y cobertura mediática ya publicada, a partir de un conjunto de registros verificables. Enfoque académico. No constituye asesoría electoral ni recomendación de voto.

Principios de integridad de datos:

  • ✓ No inventar publicaciones
  • ✓ No inventar interacciones
  • ✓ Conservar siempre fuente y URL
  • ✓ Indicar datos faltantes explícitamente
  • ✓ Diferenciar hecho, opinión y afirmación
  • ✓ No confundir cobertura con intención de voto
